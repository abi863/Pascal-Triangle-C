# Pascal Triangle in C

## Description

This program prints Pascal's Triangle using nested `for` loops in C.

## Sample Output

```text
             1
          1     1
       1     2     1
    1     3     3     1
 1     4     6     4     1
```

## Concepts Used

* Nested `for` loops
* Number pattern printing
* Arithmetic operations
* Basic C programming

## How to Run

```bash
gcc pascal_triangle.c -o pascal_triangle.exe
./pascal_triangle.exe
```

## Language

C
